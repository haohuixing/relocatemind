## 1. PRODUCT OVERVIEW & HYBRID AI STRATEGY

**RelocateMind** is a Product-Led Growth (PLG) global mobility engine that matches users with digital nomad, freelancer, and residency visa programs based on their passport country, monthly revenue ($USD), income source structure, household dependents, relocation goals, and timeline.

### Business Model & AI Architecture ("Hybrid AI")
To prevent astronomical LLM API costs while maintaining high-converting PLG mechanics, RelocateMind uses a **2-Stage Hybrid AI Strategy**:

1. **Top-of-Funnel Anonymous Quiz ($0 Token Cost)**:
   * Runs a fast, deterministic Python algorithm (`app/modules/discovery/matcher.py`).
   * Calculates hard legal requirements (minimum income thresholds, family dependent multipliers, accepted income types, EU freedom of movement) and soft scores (purchasing power buffer, quality of life, tax rates) in 100ms with **$0 API cost**.
   * Shows match percentages, cost buffers, and shortfall breakdown, while teasing deep AI reports behind free account registration ("🔒 Unlock Full AI Tax & Visa Strategy").

2. **Registered Dashboard & Pro Tier (Gated AI Generation)**:
   * Once a user creates an account, verifies their email, and accesses `/dashboard`:
   * Uses Gemini API (`google-genai` SDK) to generate personalized relocation strategy dossiers, consulate cover letters, and tax residency optimization reports cached in Supabase (`JSONB`).
   * Rate-limited AI Visa Concierge Chatbot inside the dashboard workspace.

## 2. PRODUCTION TECH STACK & DEPLOYMENT MAP

* **Backend Framework**: Python 3.10+, FastAPI (ASGI, Asynchronous routing)
* **Database & ORM**: Supabase PostgreSQL (Managed Cloud) using native `JSONB` for `matches_json` and `checklist_json`
* **Authentication & Sessions**:
  * **Supabase Auth Engine**: Email/Password authentication with Email Verification enabled.
  * **Admin Service Role Client**: Uses `SUPABASE_SERVICE_ROLE_KEY` on backend to pre-populate user profile data upon signup prior to email verification.
  * **Stateless Cookies**: `sb_access_token` (Supabase session) and `anon_test_data` (HMAC-SHA256 signed base64 payload for anonymous test migration).
* **Frontend Aesthetic**: Pure Tailwind CSS (via CDN), Inter & JetBrains Mono fonts, Glassmorphic dark mode theme (`bg-slate-950`), GPU-accelerated CSS micro-animations, zero-layout-shift CSS grid stacked interactive components.
* **Localization (i18n)**: Single-source-of-truth translation JSON (`locales/en.json`) rendered via Jinja helper `{{ t('key.path') }}` defined in `app/core/i18n.py`.
* **GitHub Repository**: `https://github.com/haohuixing/relocatemind`
* **Live Production Server**: Render Web Service (`https://relocate-mind.onrender.com`)
