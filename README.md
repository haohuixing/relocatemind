# RelocateMind - Country Relocation Discovery Engine (MVP)

An MVP built with **Python (FastAPI)**, **SQLAlchemy (SQLite)**, **Jinja2**, and **Tailwind CSS**.

## Quickstart

1. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Run server**:
   ```bash
   python -m app.main
   ```

3. **Open Browser**:
   [http://127.0.0.1:8000](http://127.0.0.1:8000)
